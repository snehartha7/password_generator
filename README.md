# 🔐 Password Generator (Python)

A simple Python-based Password Generator that generates random passwords based on the user's desired length.

This project was built to practice Python fundamentals, including loops, functions, strings, and the random module.

## 🚀 Features

- Generate random passwords.
- Customize password length.
- Include uppercase and lowercase letters.
- Include numbers and special characters.
- Simple and user-friendly interface.
- Generate multiple passwords.

## 🛠️ Technologies Used

- Python 3
- Random Module
- String Module

## 📋 Requirements

- Python 3.x installed on your system.
- VS Code or any Python-supported IDE.

## ⚙️ How to Run

###1. Clone the repository ###

```bash
git clone https://github.com/snehartha7/password_generator.git
```

###2. Navigate to the Project directory ###

```bash
cd password_generator
```

###3. Run main.py ###

```bash
python main.py
```
